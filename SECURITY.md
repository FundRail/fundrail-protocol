# Security Policy

## Supported Versions

The project is currently in early foundation setup. Security updates are handled as issues are triaged.

## Reporting a Vulnerability

Please do not open a public issue for a security concern. Instead, report it privately through the repository maintainer contact or GitHub security advisory flow if available.

Provide:

- Affected project areas
- Reproduction steps
- Impact assessment
- Suggested remediation, if known

We aim to acknowledge reports promptly and coordinate a fix with the responsible maintainer.

## Disclosure

We will work to validate and fix verified vulnerabilities as quickly as possible, while keeping the report confidential until a patch is ready.
